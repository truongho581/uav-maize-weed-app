# Tài liệu GreenEye

- `HUONG_DAN_SU_DUNG.md`: tài liệu vận hành cho người dùng.
- `requirements/`: yêu cầu phần mềm và tiêu chí nghiệm thu.
- `phase9_5/GREENEYE_MISSION_EXPORT_CONTRACT.md`: cấu trúc mission, route và media.
- `phase9/PRODUCTION_MODEL_PACK.md`: trọng số production.
- `design/`: thiết kế UI/UX và luồng thao tác.
- `roadmap/`: kế hoạch phát triển và các review theo phase.

Tài liệu phase được giữ làm lịch sử kỹ thuật. Các ảnh screenshot và file tạm không phải nguồn
phát hành; chúng không được đưa vào artifact đóng gói.
